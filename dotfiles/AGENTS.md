# グローバル指示

`AGENTS.md` `CLAUDE.md` `GEMINI.md` は全てシンボリックリンクである

- リポジトリごとの指示を優先する
- 前後の文脈で判断せずに不明瞭な部分はすぐに質問する

## 言語

- 必ず日本語で話す
- コメント・コミットメッセージ・ログ出力は英語

## コメント
- コメントはユーザーの指示を直接書かない
- 自明なことは書かない
- どうしているかよりも何をしているかを優先する
- できるだけ短くする

# Git
- メッセージは prefix(scope): description
- メッセージはできるだけ短く
- コミットを戻すときは指示した ID がそのブランチの先頭になるようにすること
- マージコミットは `--no-ff`
- マージは指示されるまで勝手に実行しない
